# 포스터 레이아웃 시안 (DLV-4.2.1) — 42×60cm 세로, 텍스트 와이어

공통 필수: 팀명(MARU) · 팀원(하도윤, 컴퓨터공학과) · 프로젝트명 크게 · 소개 · 예시화면 · 우상단 QR 자리(빈 칸, 약 7×7cm) · 토끼·거북이 크게(raw 1254px).

## 시안 A — "캐릭터 무대" (흰 바탕, 위쪽에 큰 제목 + 캐릭터 둘이 양옆에서 등장)
```
┌──────────────────────────────────────────┐
│ 팀명 MARU · 팀원 하도윤          ┌──────┐ │
│ 2026 졸업작품                    │  QR  │ │
│                                  └──────┘ │
│        M A R U                            │
│        마루 — 외국인을 위한 한국어 학습 앱 │
│  🐰(크게, 왼쪽)              🐢(크게, 오른쪽) │
│   "일단 해보자!"         "천천히 뜯어보자"   │
├──────────────────────────────────────────┤
│ INTRODUCTION  (보라 둥근 라벨)            │
│ 한국어는 붙여 만드는 언어… 3~4줄          │
├──────────┬──────────┬──────────┬─────────┤
│ M 레슨   │ A 단어    │ R 미션    │ U 실험실 │
│ [폰화면] │ [폰화면]  │ [폰화면]  │ [폰화면] │
│ 2줄 설명 │ 2줄 설명  │ 2줄 설명  │ 2줄 설명 │
├──────────┴──────────┴──────────┴─────────┤
│ TECH: Flutter · Spring Boot · PostgreSQL · Railway · FSRS-4.5 · Kiwi · OpenAI · Gemini │
└──────────────────────────────────────────┘
```
- 장점: 원본 예시 포스터(제목 크게 → INTRODUCTION → 화면 그리드)와 흐름이 같아 심사자가 읽기 쉬움. 4기능이 한 줄에 나란히 = "MARU 4글자" 가 한눈에.
- 단점: 폰 화면 4장이 한 줄이라 화면 하나가 작음(폭 약 8cm).

## 시안 B — "보라 히어로" (위 40% 보라 블록, 캐릭터가 블록 경계에 걸쳐 크게)
```
┌──────────────────────────────────────────┐
│███ 보라 #6B4EFF 배경 ██████████ ┌──────┐ │
│ 팀명 MARU · 팀원 하도윤          │  QR  │ │
│                                  └──────┘ │
│  MARU                                     │
│  마루                                      │
│  외국인을 위한 한국어 학습 앱               │
│  "🐰 빠르게 체험하고, 🐢 천천히 이해한다"   │
│████████████   🐰(매우 크게)  🐢(매우 크게) █│ ← 캐릭터가 경계에 걸침
├──────────────────────────────────────────┤
│ 소개 3줄 (흰 바탕)                         │
├─────────────────────┬────────────────────┤
│ M 레슨 [폰][폰]      │ A 단어 FSRS [폰]   │

│ R 미션 [폰][폰]      │ U 실험실 [폰]      │
│ 레드/옐로카드·판정   │ AI 문법 변형·캐시  │
├─────────────────────┴────────────────────┤
│ 시스템 구성 미니 도식 + 기술 칩            │

```
- 장점: 멀리서도 보라색·캐릭터가 확 보임(전시 폼보드용). 2×2 카드라 화면이 더 큼(폭 약 10cm).
- 단점: 보라 면적이 커서 인쇄 잉크 많음, 정보량은 A 와 비슷.

추천: **B** — 전시장 폼보드에서 시선을 끌고, 캐릭터를 "크게" 쓰라는 요구에 가장 잘 맞음.
