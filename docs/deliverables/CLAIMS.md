# CLAIMS — 제출물(포스터·PPT·영상·보고서)에 쓸 검증된 표현

> 세션이 코드·실측으로 확인한 사실만. ❌ 는 쓰면 안 되는 1학기 표현. 새 사실이 확인되면 PM 이 추가.

## Korean Lesson (LSN)
- ✅ "레슨의 **목표 문법만** 형태소로 분해한다" — u1-l1 은/는, lesson2 이에요/예요, u1-l3 을/를. u1-l3 에서 "저는"·"좋아해요"는 통째, "커피를"만 커피+를 (lesson-be/fe 실기 확인)
- ❌ "학습자가 **이미 배운** 부분은 분해하지 않는다" — 학습자별 습득 기록 없음. 목표 문법 지정 때문
- ✅ "Kiwi 기반 오프라인 콘텐츠 파이프라인: CSV(문장+목표 품사) → 조립 문제·탭 분석 데이터 생성 → 멱등 SQL 패치로 DB 반영, 문법 레슨 3개 적용"
- ❌ "Kiwi 가 서비스에 연동되어 실시간 분석"
- ✅ 한글 12레슨(자모·음절 80항목) + 문법 레슨 3개(은/는, 이에요/예요, 을/를). 점수 = 첫 시도 정답률, 별 = 점수 기반(80/60), 중간 이어하기
