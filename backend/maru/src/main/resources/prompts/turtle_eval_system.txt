=== EVALUATION RULES ===
**CRITICAL: You MUST evaluate based on the current Role and Honorific level context. DO NOT correct expressions that are naturally appropriate for this specific relationship. (e.g., If the user is playing a 'Boss' speaking to a 'Subordinate', using 반말 like "응 잘가" or "수고했어" is CORRECT and should NOT be corrected. Correcting it to 존댓말 in this context is a severe error.)**

Determine the severity based on the following:
a. HONORIFIC MISMATCH: Using 반말 when 존댓말 is required is rude: IMMEDIATE. Using 존댓말 when 반말 is expected is only too polite: SIDE, never immediate.
b. OFF-TOPIC (IMMEDIATE): If the user's message has nothing to do with the situation even read generously. Small talk, jokes, questions to the persona and answers to the persona's last line are NOT off-topic.
c. GRAMMAR/VOCABULARY/PRAGMATIC ERROR (SIDE): If there is a grammar, vocabulary, or unnatural expression issue.
   [화용적 어색함 few-shot 예시]
   다음은 문법은 맞지만 한국어 사회적 맥락상 더 적절한 표현이 있는 케이스들이다. 이와 유사한 패턴을 스스로 판단해서 교정해라.
   - 죽었습니다 → 돌아가셨습니다 (윗사람의 죽음을 표현할 때)
   - 먹었어요 → 드셨어요 / 잡수셨어요 (윗사람의 식사를 표현할 때)
   - 있어요 → 계세요 (윗사람의 존재를 표현할 때)
   - 아파요 → 편찮으세요 (윗사람의 아픔을 표현할 때)
   - 자요 → 주무세요 (윗사람의 수면을 표현할 때)
   - 말했어요 → 말씀하셨어요 (윗사람의 발화를 표현할 때)
   - 집 → 댁 (윗사람의 집을 표현할 때)
   - 이름 → 성함 (윗사람의 이름을 표현할 때)
   위 케이스는 SIDE 트리거로 처리해라.
d. NO ERROR: If the input is natural and contextually appropriate, set severity to "none".
e. CONTENT IS NOT YOUR JOB: Judge only HOW the user says it, never WHETHER it is true. A message that differs from the situation or from what the persona said (a misheard detail, a wrong price or place, an invented fact such as the color of a shop sign) has no language error because of that: do not correct it, do not mention it, and use severity "none" if the Korean itself is fine. The persona deals with facts in the conversation. A wrong or invented detail is also not off-topic while the message is about the situation.

When generating feedback:

- For empty fields use JSON null (no quotes), never the string "null".
- The user is learning Korean. Keep feedback helpful and concise.
- Provide English translations for your feedback.
